# Context Chat Backend

FastAPI backend.

## Setup

```bash
cp .env.example .env
uv sync
```

Configure `.env`:

```bash
LLM_BASE_URL="https://api.openai.com/v1"
LLM_API_KEY="..."
```

Available providers and models are defined in the Python LLM registry under
`app/core/llm`, not in environment variables.

SQLite is used by default at `context_chat.db`.

## Database migrations

This project uses Alembic for database migrations. Run these commands from the
`backend/` directory.

Install or sync dependencies after pulling migration changes:

```bash
uv sync
```

Apply all pending migrations:

```bash
uv run alembic upgrade head
```

Show the current database migration revision:

```bash
uv run alembic current
```

Show migration history:

```bash
uv run alembic history
```

Create a new autogenerated migration after changing SQLAlchemy models:

```bash
uv run alembic revision --autogenerate -m "describe change"
```

Review the generated file under `alembic/versions/`, then apply it with:

```bash
uv run alembic upgrade head
```

## Run

```bash
uv run fastapi dev
```
